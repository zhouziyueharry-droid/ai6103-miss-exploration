# MiSS 前期实验方案

日期：2026-11-05。范围：六人组的两个候选方向之一，由三人探索。当前没有训练结果。

## 1. 我们要回答的问题

在一个可负担的小型 LLM 上，能否对 MiSS 做出可重复、成本可接受的改进？

先把原版方法跑正确，再把同一训练程序中的 adapter 换成改进版。只有这组受控比较才能说明改进是否有用。换一个更强的基础模型后分数提高，不能算算法改进。

这是原方法在新规模上的实现核验和扩展验证，不是完整复现论文的原模型、训练集和超参数。

## 2. 暂定任务、数据与模型

| 项目 | 本轮选择 | 原因与边界 |
|---|---|---|
| 任务 | 数学文字题的监督微调（SFT） | 输入题目，输出解题过程及最终数值；可自动评分，不需要奖励模型或在线 rollout |
| 数据 | `openai/gsm8k`，`main` | 官方 train 7,473 条，test 1,319 条；已有 question / answer 字段 |
| 流程检查模型 | `Qwen/Qwen3-0.6B` | 只检查数据、训练、保存、加载和评测链路，效果差不能直接否定 MiSS |
| 探索模型 | `Qwen/Qwen3-1.7B` | 与原文 Qwen3-4B 同家族但规模不同；这是规模扩展，不是新架构 |
| 主训练模式 | 非 thinking，BF16，标准 MiSS | 避免把 thinking 开关、量化或 bat/mini 混进第一轮对照 |

这些是可调整的探索默认值，不是你们已经最终选定的课程项目范围。16GB 卡能否按指定配置跑通需要实测；H100 可用于加速，但不先扩大模型。

原论文的数学训练使用 MetaMathQA 子集，代码训练使用 CodeFeedback。我们用较小的 GSM8K train，主要为了快速检验优化方向。**不能把本轮分数直接与论文表 5 作高低比较。**

模型的预训练/后训练可能已接触相关基准，不能据此宣称完全未见数据泛化。对照必须使用同一个模型 revision，结论限定在本实验协议内。

## 3. Baseline 应当怎么选

| 对照 | 地位 | 回答的问题 |
|---|---|---|
| 未微调的 Qwen3-1.7B | 起点，按固定协议评测一次 | 原模型已经会多少，微调有没有破坏能力？ |
| 原版标准 MiSS | 必须，有效性的主要 baseline | 我们的改动是否优于原方法？ |
| LoRA | 实用性 baseline | 即使比 MiSS 好，是否仍不如普通 LoRA？ |
| 改进版 MiSS | 探索对象 | 优化收益是否稳定，代价是什么？ |

DoRA 暂不放进最小探索矩阵，避免一开始把算力花在太多对照上。六人组决定继续后再扩展。

第一轮 adapter 统一覆盖 q/k/v/o 和 MLP gate/up/down 投影，不训练基础权重、词嵌入和 lm_head。所有方法都打印实际 trainable parameter count。

对 Qwen3-1.7B 的这些层，按已下载模型配置推算：标准 MiSS r=16 约 9,175,040 个参数，LoRA r=8 约 8,716,288 个参数，MiSS 约多 5.26%。这是解析估算，注入后必须核验。两者不是严格预算匹配，不能据此下参数效率结论；先做实用对照，后续可按层调整 rank 做匹配。

同一 MiSS r=16 上加每输入分片一个静态标量，预计只新增 32,256 个参数（约 0.352%）。仍需按代码实测并披露，不能把额外参数藏起来。

## 4. 数据协议

1. 从官方 train 按固定 split_seed=2026 做 90%/10% 划分。保存每条样本的原始索引和文本 SHA256。所有方法、训练 seed 共用同一划分。
2. 试跑从训练部分固定抽 128 条，验证部分固定抽 16 条；探索从训练部分固定抽 2,048 条，验证部分固定抽 128 条。禁止每种方法重新抽样。
3. 官方 test 在前期探索阶段保持不用。选择方法、rank、学习率、检查失败例子都只用训练集和验证集。
4. chat template 固定 `enable_thinking=False`。使用官方模板，训练和推理的用户提示一致，要求最终答案格式 `#### 数字`。
5. 仅 assistant 回答 token 参与 loss。用户 prompt 和 padding 标为 -100。保留 assistant 结束符，检查截断后仍有有效监督 token，并统计截断比例。
6. GSM8K 的 `<<...>>` 计算标记采用固定规则去除，保留数学文本和 `####` 答案。预处理版本、处理前后样例必须保存。

最终评估时，从输出中提取最后一个符合协议的 `####` 数值，去除千分位逗号和周围空白，按十进制数精确比较。提取失败计错，并单独报告比例。不悄悄改成“取最后一个数字”来抬高分数。

前期固定非 thinking + greedy decoding + max_new_tokens=512，不为每种方法单独改生成设置。需要记录达到生成上限的比例。若大量输出截断，应统一调整协议并重跑所有对照。

## 5. 前期实验顺序

### E0：接通链路

Qwen3-0.6B，128 条训练数据，32 个 optimizer steps，micro batch=1，gradient accumulation=8，序列长度 512，SDPA，gradient checkpointing。

通过条件：有限 loss、有效标签、只有指定 adapter 参数更新、能保存/加载、相同输入在 eval 模式下重载输出一致、评测解析器通过人工样例检查。

这一步只证实程序能跑，不能说明算法有效。不要为 E0 的准确率调参。

### E1：建立主模型原版基线

先在 Qwen3-1.7B 上完成 20–30 步显存探测，再执行 2,048 条数据、200 optimizer steps 的探索配置。默认 micro batch=1、accumulation=8、max_length=1024、lr=2e-4。该学习率是探索起点，不是原论文设置或已验证最优值。

先各跑一次原版 MiSS 和 LoRA；若 loss/输出异常，先检查实现、数据与学习率，不把失败归因于方法本身。两种方法都允许相同规模的小型学习率试验，例如 {5e-5, 2e-4}，所有试验都计入预算。

### E2：只试一个改进

优先候选：标准 MiSS 的每分片可学习缩放。原版 Δy=(Σx_i)D，候选 Δy=(Σg_i x_i)D。

- g 初始化为 1，D 保持原版的零初始化；不要同时把 g 和 D 初始化为零。
- g 在首步梯度为零是预期行为；D 更新后再检查 g 的梯度。
- 保持数据、训练步数、原版 D 的优化器配置等不变，明确 g 的 weight decay 策略。建议 g 使用零 weight decay。
- 先核验 g=1 时与原版的前向和 D 梯度一致，再检查保存、加载和合并。
- 冻结 W₀，只训练 D 与 g。部署时静态 g 可合入各分片更新，但需要数值一致性检查。

这只是候选研究假设。可学习缩放和参数共享已有先例，需要对照 VeRA、MiSS 的 bat/mini 及其他相关工作查重。不要声称首创，也不要把已有 PEFT 开关当成自己的优化。

有正向迹象后，在固定配置上补第二个训练 seed（42、43）。主比较为原版 MiSS / 改进 MiSS；LoRA 同样补 seed 才能比较稳定性。一个 task 的最多六次短训练是起始矩阵，不是最终论文实验量。

### E3：解释收益或及时止损

若分片加权表现较好，补“每层仅一个全局缩放”的消融，判断收益是否只是更新幅度/优化动态变化；全局缩放可以被 D 吸收，本身不扩大函数表达集合。

如果没有信号，先做一个有理由的排错或调整，例如检查梯度、截断、学习率。不得反复看验证集、无限换 seed 或只保留有利结果。每次变化都登记。

## 6. 给六人组的继续／放弃判断

建议给此方向设一个共同认可的 GPU 小时上限。配置中暂列 8 GPU 小时，包含评测与调参，只作为可修改预算建议，不是耗时预测，也不授权租卡。

继续探索的证据至少包括：

- 两个训练 seed 上改进相对原版方向一致，收益超过测量噪声；同时报告逐题差异，128 条验证样本不能支撑强统计结论。
- 任务分数、验证 loss、格式成功率、截断率的变化有合理解释。
- 训练时间与显存代价透明。默认把超过 20% 的训练耗时增加作为重新讨论收益是否值得的信号，而不是自动宣称失败。
- 代码改动独立可复跑，合并/保存行为正常，相关工作中没有发现完全相同且被误称原创的实现。

如果只有单 seed 小幅优势、仅训练 loss 下降、或者比较配置不一致，结论是“证据不足”。如果正确实现后多个 seed 无改善、预算耗尽或实现代价过高，就向六人组建议暂停该方向，保留负结果。

## 7. 三人前期分工

| 临时角色 | 探索职责 | 给其他人的交付 |
|---|---|---|
| A：原版训练与环境 | GPU 环境、固定版本、原版 MiSS 和 LoRA、显存及速度记录 | 环境锁文件、baseline 日志、参数统计、可复跑命令 |
| B：数据与独立评测 | 固定划分、模板与 mask、数值解析、逐题输出检查 | splits 清单、评测器、未微调基线、对照结果表 |
| C：优化假设与实现 | 核对论文、查重、分片加权最小实现、正确性检查 | 独立改动、消融方案、优化日志、失败分析 |

A 和 B 先约定训练/评测接口，C 复用同一入口和划分。最终三人共同提交一份探索报告给六人组，而不是分别开展三个互不一致的小项目。
